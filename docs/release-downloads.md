## Downloads

Most people need only three zips: `kb-note`, `kb-query` and `kb-ingest`, either all three plain or all three `-zh`.

| File | Use it for |
| --- | --- |
| `kb-note-<version>.zip`, `kb-query-<version>.zip`, `kb-ingest-<version>.zip` | unpack each into `.claude/skills/` of your library repository, then commit and push |
| `kb-note-<version>-zh.zip`, `kb-query-<version>-zh.zip`, `kb-ingest-<version>-zh.zip` | the same skills with Chinese trigger phrases (中文口令版) |
| `repo-wiki-v<version>.zip` | the whole repository: skills, docs and the sample library |

Setup: [docs/setup.md](https://github.com/walkwithedi/repo-wiki/blob/main/docs/setup.md) ([中文](https://github.com/walkwithedi/repo-wiki/blob/main/docs/setup.zh-CN.md)).
